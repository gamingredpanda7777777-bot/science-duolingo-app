# 과학 학습 프로그램 — 배포하고 계속 업데이트하는 방법

이 폴더는 그대로 웹에 올릴 수 있는 프로젝트예요.
목표는 **한 번 세팅해두고, 이후에는 문제를 고칠 때마다 자동으로 앱이 갱신되는 것**이에요.

---

## 1. 준비물 (전부 무료)

| 필요한 것 | 용도 |
|---|---|
| [Node.js](https://nodejs.org) LTS 버전 | 내 컴퓨터에서 앱을 실행·빌드 |
| [GitHub](https://github.com) 계정 | 코드 보관 + 업데이트 기록 |
| [Vercel](https://vercel.com) 계정 | 실제 배포 (GitHub 계정으로 가입 가능) |

카드 등록 없이 무료 요금제로 충분해요.

---

## 2. 내 컴퓨터에서 먼저 확인하기

이 폴더에서 터미널(명령 프롬프트)을 열고:

```bash
npm install
npm run dev
```

`http://localhost:5173` 이 뜨면 브라우저로 열어 확인해요.
문제가 잘 풀리는지, 스크롤이 되는지 여기서 먼저 보고 넘어가요.

멈추려면 터미널에서 `Ctrl + C`.

---

## 3. GitHub에 올리기

GitHub에서 새 저장소(repository)를 하나 만들어요. 이름은 `science-duolingo` 정도로.
그리고 이 폴더에서:

```bash
git init
git add .
git commit -m "과학 학습 프로그램 첫 배포"
git branch -M main
git remote add origin https://github.com/내아이디/science-duolingo.git
git push -u origin main
```

`내아이디` 부분은 본인 GitHub 아이디로 바꿔야 해요.

---

## 4. Vercel로 배포하기

1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 로그인
2. **Add New → Project** 클릭
3. 방금 올린 `science-duolingo` 저장소 선택
4. 설정은 건드릴 것 없이 그대로 **Deploy** 클릭

1~2분 뒤 `https://science-duolingo.vercel.app` 같은 주소가 나와요.
**이 주소를 친구들에게 그대로 공유하면 돼요.** 앱 설치도 가입도 필요 없어요.

---

## 5. ★ 배포 후 업데이트하는 방법 (제일 중요)

한 번 4번까지 해두면, 이후에는 **이 세 줄이 전부**예요.

```bash
git add .
git commit -m "5단원 문제 30개 추가"
git push
```

`git push` 하는 순간 Vercel이 자동으로 감지해서 다시 배포해요.
1~2분 뒤면 접속한 모든 사람에게 새 문제가 반영돼요. **주소는 그대로예요.**

즉 앞으로 5단원 문제를 만들 때마다:

1. `src/App.jsx` 에서 문제 배열에 문제를 추가하고
2. `npm run dev` 로 잘 되는지 확인하고
3. 위 세 줄로 push

이게 전부예요.

## 6. 휴대폰 홈 화면에 앱처럼 추가하기

이 앱은 PWA로 설정돼 있어서, 앱스토어 없이 홈 화면에 넣을 수 있어요.

- **아이폰**: 사파리로 접속 → 공유 버튼 → "홈 화면에 추가"
- **안드로이드**: 크롬으로 접속 → 메뉴 → "홈 화면에 추가"

추가하면 주소창 없이 진짜 앱처럼 열려요.

## 7. 배포 전 정리 — 완료된 항목

아래 세 가지는 이미 적용되어 있어요.

### (1) 학습 기록 저장 ✅
`src/lib/progress.js`에서 `localStorage`로 기기에 저장해요. 계정도 서버도 필요 없어요.

- **경험치와 레벨**: 정답 1개당 10 XP, 100 XP마다 레벨 1 상승
- **연속 학습일**: 어제도 했으면 +1, 하루라도 건너뛰면 1로 초기화
- **레슨별 최고 기록**: 다시 풀어서 점수가 낮아져도 최고 기록은 유지돼요
- **오답 다시 풀기**는 기록에 반영되지 않아요 (전체 레슨을 푼 게 아니니까요)
- 사파리 비공개 모드처럼 저장이 막힌 환경에서도 앱이 죽지 않아요

### (2) 가짜 숫자 제거 ✅
`Lv.8`, `에너지 80`, `연속 학습 7일` 같은 고정값을 전부 실제 기록과 연결했어요.
"에너지"는 의미가 불분명해서 **"다음 레벨까지"** 진행률로 바꿨어요.

### (3) 면책 문구 ✅
홈 화면 맨 아래에 표시돼요.

> 이 앱의 문제와 해설은 **AI가 만든 학습 참고용 자료**이며, 공식 교재나 기출 문제가 아니에요.
> 오류가 있을 수 있으니 교과서와 함께 확인하며 사용해 주세요.

같은 자리에 "학습 기록 초기화" 버튼도 있어요 (확인 창을 한 번 거쳐요).

## 8. 폴더 구조 — 문제는 어디에 있나

문제 데이터와 화면 코드가 분리되어 있어요.
**문제를 추가·수정할 때는 `src/data/` 안의 파일만 열면 돼요.** `App.jsx`는 건드릴 일이 거의 없어요.

```
src/
  App.jsx                    화면과 퀴즈 동작 (문제 데이터 없음)
  main.jsx                   진입점
  data/
    subjects.js              ★ 과목 → 모듈 → 레슨 등록표
    physics.js               물리 문제
    unit4-sense.js           4단원 감각 기관 (눈·귀·피부·혀·코) 40문제
    unit4-nerve.js           4단원 신경계 40문제 중 30문제
    unit4-homeostasis.js     4단원 항상성 20문제
    unit4-advanced.js        4단원 단답형·초고난도 20문제
```

### 5단원 문제를 추가하는 순서

**1)** `src/data/unit5-xxx.js` 파일을 새로 만들고 문제를 넣어요.

```js
export const UNIT5_SOME_QUESTIONS = [
  {
    id: "std_bio_u5_a_q01",
    difficulty: "easy",
    stem: "문제 내용",
    choices: ["①", "②", "③", "④"],
    answerIndex: 0,
    explanation: "해설",
  },
];
```

**2)** `src/data/subjects.js` 맨 위에서 불러오고,

```js
import { UNIT5_SOME_QUESTIONS } from "./unit5-xxx.js";
```

**3)** 같은 파일의 `SUBJECTS` 안에 레슨으로 등록해요.

```js
{
  id: "std_bio_u5_a_lesson",
  title: "레슨 이름",
  status: "available",
  questions: UNIT5_SOME_QUESTIONS,
},
```

이렇게만 하면 앱 화면에 자동으로 나타나요.

### 문제 형식 세 가지

| 형식 | 필요한 항목 |
|---|---|
| 4지선다 | `choices` 4개 + `answerIndex` |
| ㄱㄴㄷ 5지선다 | `boxItems` 3개 + `choices` 5개 + `answerIndex` |
| 단답형 | `type: "short_answer"` + `answers` 배열 (정답으로 인정할 표기들) |

단답형의 `answers`에는 여러 표기를 넣어두면 좋아요. 띄어쓰기와 문장부호는 자동으로 무시돼요.

```js
answers: ["귓속뼈", "귓속 뼈"]
```

## 9. 미리보기용 단일 파일

미리보기 화면은 **파일 하나만 실행**할 수 있어서, `import`로 나뉜 이 프로젝트를 그대로 열지 못해요.
그래서 전부 하나로 합친 파일을 따로 만들어요.

```bash
npm run build:preview
```

`preview/science_duolingo_app.jsx` 가 만들어져요. 이 파일을 미리보기에 넣으면 돼요.

**원본은 언제나 `src/` 폴더예요.** 문제를 고칠 때는 `src/data/` 를 고치고,
미리보기로 확인하고 싶을 때만 위 명령을 다시 실행하세요.
`preview/` 안의 파일을 직접 고치면 다음 실행 때 덮어써져요.

## 10. 서버 연결하기 (Supabase)

서버를 붙이면 **다른 기기에서도 같은 아이디로 로그인**할 수 있고, 비밀번호가 제대로 보호돼요.
연결하지 않으면 앱은 그대로 "이 기기에만 저장" 모드로 동작해요. 언제든 나중에 붙여도 돼요.

### 1) Supabase 프로젝트 만들기

1. [supabase.com](https://supabase.com) 에 GitHub 계정으로 가입
2. **New project** → 이름과 비밀번호(데이터베이스용) 정하고 생성
3. 지역은 `Northeast Asia (Seoul)` 을 고르면 빨라요

### 2) 데이터베이스 만들기

왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/schema.sql` 파일 내용을 전부 붙여넣고 **Run**.
테이블 2개(profiles, progress)와 보안 정책이 한 번에 만들어져요.

### 3) 이메일 확인 끄기 ★ 꼭 필요해요

**Authentication → Providers → Email** 에서 **Confirm email** 을 **꺼 주세요**.
이 앱은 실제 이메일을 받지 않기 때문에, 켜져 있으면 가입은 되는데 로그인이 막혀요.

### 4) 키 넣기

**Project Settings → API** 에서 두 값을 복사해요.

```bash
cp .env.example .env
```

`.env` 파일을 열어 채워요.

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGci...
```

`anon key` 는 공개되어도 되는 키예요. 브라우저에서 쓰라고 만든 것이고, 실제 보호는
3단계에서 만든 보안 정책(RLS)이 담당해요. **`service_role` 키는 절대 넣으면 안 돼요.**

`.env` 는 git 에 올라가지 않도록 이미 막아뒀어요.

### 5) Vercel 에도 같은 키 넣기

Vercel 프로젝트 → **Settings → Environment Variables** 에 위 두 값을 똑같이 추가하고 재배포해요.
이걸 빼먹으면 배포된 앱만 로컬 모드로 동작해요.

### 확인하는 법

로그인 화면 아래 안내 문구가 바뀌어요.

- 서버 모드: "계정과 학습 기록이 **서버에 저장**돼요"
- 로컬 모드: "계정과 학습 기록은 **이 기기에만** 저장돼요"

### 설계 요약

| 항목 | 내용 |
|---|---|
| 고유 코드 | 서버가 자동 생성. 10자리. 트리거로 변경을 막아둠 |
| 아이디 | 변경 가능. 대소문자 구분 없이 중복 불가 |
| 비밀번호 | Supabase 가 안전하게 보관. 앱은 원문을 저장하지 않음 |
| 로그인 | 아이디 또는 고유 코드 + 비밀번호 |
| 학습 기록 | 로그인하면 서버에서 불러오고, 풀 때마다 자동 저장 |

아이디로 로그인할 수 있도록 내부적으로 가짜 이메일 주소를 하나씩 발급해요.
사용자에게는 보이지 않고, 아이디를 바꿔도 그대로 유지돼서 로그인이 계속 동작해요.

## 11. 개념 영상 넣기

레슨에 영상을 붙이면, 그 레슨을 눌렀을 때 문제보다 영상이 먼저 나와요.
`src/data/subjects.js` 에서 레슨에 `video` 한 줄만 추가하면 돼요.

### 방법 A — 파일로 넣기 (지금 눈 영상이 이 방식)

1. 영상 파일을 `public/videos/` 폴더에 넣어요. 이름은 영문으로 (예: `unit4-ear.mp4`)
2. 레슨에 경로를 적어요.

```js
{
  id: "std_bio_sense_b_ear_lesson",
  title: "귀",
  status: "available",
  video: "/videos/unit4-ear.mp4",   // ← 이 줄
  questions: EAR_QUESTIONS,
},
```

3. `git push` 하면 영상도 같이 올라가요.

**주의** — 영상 하나가 보통 10~30MB라, 파일이 20개쯤 되면 저장소가 수백 MB가 돼요.
그 정도 되면 방법 B로 옮기는 게 좋아요. GitHub은 파일 하나가 100MB를 넘으면 거부해요.

### 방법 B — 유튜브로 넣기 (영상이 많아지면 추천)

1. 유튜브에 영상을 올릴 때 공개 범위를 **"일부 공개(미등록)"** 로 해요. 링크 있는 사람만 볼 수 있어요.
2. 영상 주소를 그대로 적어요.

```js
video: "https://youtu.be/영상아이디",
```

`youtu.be/...`, `youtube.com/watch?v=...`, `youtube.com/shorts/...` 어떤 형태든 돼요.
용량 걱정이 없고, 유튜브가 알아서 화질을 맞춰주니 폰에서도 잘 나와요.

### 영상을 빼고 싶으면

`video:` 줄을 지우면 돼요. 그 레슨은 바로 문제로 들어가요.
